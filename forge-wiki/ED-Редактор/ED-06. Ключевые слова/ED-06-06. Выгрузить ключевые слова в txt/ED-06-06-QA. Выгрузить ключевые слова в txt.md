# Критерии успеха

1. SM-6 «Данные не теряются при переносе» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-24 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-06-06-BE и ED-06-06-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в приложении есть проект с идентификатором из пути;
   2. действие — GET /api/projects/{pid}/keywords/export;
   3. ожидается — ответ — файл нужного формата с именем объекта; тело не пустое.

# Проверки БД

Операция не меняет данные в базе: проверки БД не требуются.

# E2E (Playwright)

1. UJ-5 «Сохранить и перенести данные»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Выгрузить ключевые слова в txt» по шагам FE-дока этой фичи;
   3. ожидается — Возвращает справочник ключевых слов как текстовый файл keywords.txt: строка «КОД: синоним1, синоним2».
