1. При получении запроса POST /api/projects/{pid}/keywords/import сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'projects' запись, где 'projects.id' = 'pid':

      1. если запись не найдена → NotFoundError.
   3. Разобрать 'text' построчно:

      1. пустые строки и строки, начинающиеся с '#', пропустить;
      2. код — часть до первого ':' без ведущего '$', синонимы — часть после, через запятую; строка без кода увеличивает 'skipped';
      3. при повторе кода в файле побеждает последняя строка.
   4. Для каждого разобранного кода в таблице 'keywords' проекта:

      1. если запись с таким 'name' без учёта регистра есть → заменить 'synonyms' и увеличить 'updated';
      2. иначе создать запись и увеличить 'added'.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД                        |
|:---------------|:-------------------------------------|
| added          | число созданных записей 'keywords'   |
| updated        | число обновлённых записей 'keywords' |
| skipped        | число строк без кода                 |
