# Критерии успеха

1. SM-6 «Данные не теряются при переносе» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-24 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-06-07-BE и ED-06-07-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в приложении есть проект с идентификатором из пути; в теле переданы 'text' = 'OFF: выключи, погаси\nON: включи';
   2. действие — POST /api/projects/{pid}/keywords/import;
   3. ожидается — операция выполнена, ответ соответствует контракту.
2. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — POST /api/projects/{pid}/keywords/import;
   3. ожидается — NotFoundError.

# Проверки БД

Ключевые слова импортированы:

```sql
SELECT name, synonyms FROM keywords WHERE project_id = :pid ORDER BY name;
```

# E2E (Playwright)

1. UJ-5 «Сохранить и перенести данные»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Загрузить ключевые слова из txt» по шагам FE-дока этой фичи;
   3. ожидается — Добавляет новые и обновляет существующие ключевые слова проекта из текста.
