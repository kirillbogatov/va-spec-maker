# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются. Действие вызывается из меню «Экспорт» проекта.

# Метод

1. GET /api/projects/{pid}/export

# Функциональные требования

1. Контролы меню: «Весь проект — Word (.docx)», «Весь проект — Markdown (.md)».
2. По выбору вызвать GET /api/projects/{pid}/export:

   1. передать значения:

      1. 'pid' — идентификатор открытого проекта;
      2. 'format' — docx или md по выбранному контролу;
      3. 'lang' — язык спецификации проекта;
      4. 'intentMode' — режим описания интентов проекта;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
3. Сохранить полученный файл с названием проекта.
