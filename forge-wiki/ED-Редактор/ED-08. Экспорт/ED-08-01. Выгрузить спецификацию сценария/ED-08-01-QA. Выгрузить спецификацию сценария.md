# Проверки

1. Успешный запрос:

   1. предусловие — существует сценарий с идентификатором из пути;
   2. действие — GET /api/scenarios/{id}/export с 'format' = 'docx', 'lang' = 'ru', 'intentMode' = 'both';
   3. ожидается — ответ — файл нужного формата с именем объекта; тело не пустое.
2. Недопустимый формат:

   1. предусловие — существует сценарий с идентификатором из пути;
   2. действие — GET /api/scenarios/{id}/export с 'format' = 'pdf';
   3. ожидается — BadRequestError.
3. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — GET /api/scenarios/{id}/export;
   3. ожидается — NotFoundError.
