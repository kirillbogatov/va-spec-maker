# Критерии успеха

1. SM-6 «Данные не теряются при переносе» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-49 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-01-07-BE и ED-01-07-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в теле переданы 'version' = 1; 'name' = 'Умный дом';
   2. действие — POST /api/projects/import;
   3. ожидается — операция выполнена, ответ соответствует контракту.
2. Пустое название:

   1. предусловие — ;
   2. действие — POST /api/projects/import с 'name' = пустая строка;
   3. ожидается — BadRequestError.

# Проверки БД

Проект из дампа создан:

```sql
SELECT id, name FROM projects WHERE id = :id;
```

# E2E (Playwright)

1. UJ-5 «Сохранить и перенести данные»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Импортировать проект» по шагам FE-дока этой фичи;
   3. ожидается — Создаёт новый проект из дампа. Дампы прежних версий приводятся к текущей модели.
