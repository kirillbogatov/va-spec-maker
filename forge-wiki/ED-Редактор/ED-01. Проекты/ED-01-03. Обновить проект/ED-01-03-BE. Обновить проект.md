1. При получении запроса PATCH /api/projects/{id} сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'projects' запись, где 'projects.id' = 'id':

      1. если запись не найдена → NotFoundError.
   3. Валидировать запрос:

      1. если передан 'name' → после удаления пробелов по краям не пусто, иначе BadRequestError;
      2. если 'name' или 'description' не переданы → оставить текущие значения.
   4. Обновить запись в таблице 'projects': 'name', 'description'.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД          |
|:---------------|:-----------------------|
| id             | 'projects.id'          |
| name           | 'projects.name'        |
| description    | 'projects.description' |
