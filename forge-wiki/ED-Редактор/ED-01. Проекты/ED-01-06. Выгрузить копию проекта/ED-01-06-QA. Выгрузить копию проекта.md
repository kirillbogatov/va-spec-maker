# Критерии успеха

1. SM-6 «Данные не теряются при переносе» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-49 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-01-06-BE и ED-01-06-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — существует проект с идентификатором из пути;
   2. действие — GET /api/projects/{id}/dump;
   3. ожидается — ответ соответствует схеме контракта; состав и порядок элементов как в BE-доке.
2. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — GET /api/projects/{id}/dump;
   3. ожидается — NotFoundError.

# Проверки БД

Операция не меняет данные в базе: проверки БД не требуются.

# E2E (Playwright)

1. UJ-5 «Сохранить и перенести данные»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Выгрузить копию проекта» по шагам FE-дока этой фичи;
   3. ожидается — Возвращает полный дамп проекта в JSON для резервной копии и переноса.
