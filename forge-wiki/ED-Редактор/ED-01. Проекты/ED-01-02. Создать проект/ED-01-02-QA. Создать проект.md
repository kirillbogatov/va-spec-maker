# Критерии успеха

1. SM-1 «Полный цикл без разработчика» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-1 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-01-02-BE и ED-01-02-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в теле переданы 'name' = 'Умный дом'; 'description' = 'Голосовой ассистент для квартиры';
   2. действие — POST /api/projects;
   3. ожидается — объект создан, в ответе его идентификатор и переданные значения.
2. Пустое название:

   1. предусловие — ;
   2. действие — POST /api/projects с 'name' = пустая строка;
   3. ожидается — BadRequestError.

# Проверки БД

Запись создана в таблице 'projects':

```sql
SELECT id, name FROM projects WHERE id = :id AND name = :name;
```

# E2E (Playwright)

1. UJ-1 «Описать словарь проекта»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Создать проект» по шагам FE-дока этой фичи;
   3. ожидается — Создаёт пустой проект.
