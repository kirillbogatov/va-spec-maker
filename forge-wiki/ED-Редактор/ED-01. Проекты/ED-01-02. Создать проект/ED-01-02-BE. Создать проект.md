1. При получении запроса POST /api/projects сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Валидировать запрос:

      1. 'name' после удаления пробелов по краям не пусто, иначе BadRequestError;
      2. 'description' — по умолчанию пустая строка.
   3. Создать запись в таблице 'projects': 'name', 'description'.
   4. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД          |
|:---------------|:-----------------------|
| id             | 'projects.id'          |
| name           | 'projects.name'        |
| description    | 'projects.description' |
