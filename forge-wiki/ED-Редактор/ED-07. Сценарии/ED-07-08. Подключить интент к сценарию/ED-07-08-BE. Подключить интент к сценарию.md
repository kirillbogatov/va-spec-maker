1. При получении запроса PUT /api/scenarios/{sid}/intents/{iid} сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблицах 'scenarios' и 'intents' записи по 'sid' и 'iid':

      1. если сценария или интента нет, либо они из разных проектов → NotFoundError.
   3. Создать запись в таблице 'scenario_intents', если интент ещё не подключён: 'position' = следующий по порядку; признак 'is_global' подключённого интента не менять.
   4. Если передан 'is_global':

      1. если 'is_global' = false и у сценария есть записи 'scenario_steps' с 'kind' = 'global' для этого интента → InUseError;
      2. обновить 'scenario_intents.is_global'.
   5. Записать подключение или смену глобальности в 'scenario_history'.
   6. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД                |
|:---------------|:-----------------------------|
| id             | 'scenario_intents.intent_id' |
| is_global      | 'scenario_intents.is_global' |
