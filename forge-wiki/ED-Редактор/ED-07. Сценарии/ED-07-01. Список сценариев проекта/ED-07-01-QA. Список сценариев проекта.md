# Критерии успеха

1. SM-3 «Схема даёт однозначную таблицу» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-28 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-07-01-BE и ED-07-01-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в приложении есть проект с идентификатором из пути;
   2. действие — GET /api/projects/{pid}/scenarios;
   3. ожидается — ответ соответствует схеме контракта; состав и порядок элементов как в BE-доке.

# Проверки БД

Операция не меняет данные в базе: проверки БД не требуются.

# E2E (Playwright)

1. UJ-2 «Собрать сценарий диалога»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Список сценариев проекта» по шагам FE-дока этой фичи;
   3. ожидается — Возвращает сценарии проекта с числом строк.
