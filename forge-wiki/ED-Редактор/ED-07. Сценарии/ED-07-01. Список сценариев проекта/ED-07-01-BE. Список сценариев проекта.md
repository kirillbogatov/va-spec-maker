1. При получении запроса GET /api/projects/{pid}/scenarios сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'scenarios' все записи, где 'scenarios.project_id' = 'pid'.
   3. Для каждого сценария посчитать записи 'scenario_steps' с 'scenario_id' = 'scenarios.id'.
   4. Применить сортировку:

      1. 'scenarios.id' — ASC.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД                           |
|:---------------|:----------------------------------------|
| []             | строки таблицы 'scenarios' проекта      |
| [].id          | 'scenarios.id'                          |
| [].name        | 'scenarios.name'                        |
| [].step_count  | число записей 'scenario_steps' сценария |
