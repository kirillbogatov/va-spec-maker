# Критерии успеха

1. SM-1 «Полный цикл без разработчика» — проверяется сценариями ниже: запросы к контракту и E2E.
2. SM-2 «Единая правда об объектах» — проверяется сценариями ниже: запросы к контракту и E2E.
3. FR-29 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-07-13-BE и ED-07-13-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в проекте есть сценарий с идентификатором из пути; в проекте есть промпт с идентификатором из пути;
   2. действие — DELETE /api/scenarios/{sid}/prompts/{pid};
   3. ожидается — ответ без тела; повторный GET того же объекта возвращает NotFoundError.
2. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — DELETE /api/scenarios/{sid}/prompts/{pid};
   3. ожидается — NotFoundError.
3. Объект используется в сценарии:

   1. предусловие — на объект ссылаются строки или состояния сценария;
   2. действие — DELETE /api/scenarios/{sid}/prompts/{pid};
   3. ожидается — InUseError; в 'details.uses' число ссылок.

# Проверки БД

Подключение снято, промпт остался:

```sql
SELECT (SELECT COUNT(*) FROM scenario_prompts WHERE scenario_id = :sid AND prompt_id = :pid) AS link, (SELECT COUNT(*) FROM prompts WHERE id = :pid) AS prompt; -- link = 0, prompt = 1
```

# E2E (Playwright)

1. UJ-2 «Собрать сценарий диалога»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Отключить промпт от сценария» по шагам FE-дока этой фичи;
   3. ожидается — Снимает подключение промпта к сценарию; сам промпт остаётся в проекте.
