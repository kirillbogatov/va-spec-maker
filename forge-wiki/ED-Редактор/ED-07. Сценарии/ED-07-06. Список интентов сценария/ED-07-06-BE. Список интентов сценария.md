1. При получении запроса GET /api/scenarios/{sid}/intents сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'scenario_intents' все записи, где 'scenario_id' = 'sid', и соответствующие записи 'intents'.
   3. Применить сортировку:

      1. 'scenario_intents.position' — ASC;
      2. 'scenario_intents.id' — ASC.
   4. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API  | Параметр в БД                                  |
|:----------------|:-----------------------------------------------|
| []              | строки 'scenario_intents' сценария             |
| [].id           | 'intents.id'                                   |
| [].name         | 'intents.name'                                 |
| [].enabled      | 'intents.enabled'                              |
| [].phrase_count | число записей 'intent_phrases' интента         |
| [].hint         | 'intents.comment', иначе первая непустая фраза |
| [].is_global    | 'scenario_intents.is_global'                   |
| [].scenarios[]  | сценарии интента через 'scenario_intents'      |
