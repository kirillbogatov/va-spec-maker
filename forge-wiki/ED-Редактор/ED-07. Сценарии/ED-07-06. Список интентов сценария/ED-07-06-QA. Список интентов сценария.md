# Критерии успеха

1. SM-1 «Полный цикл без разработчика» — проверяется сценариями ниже: запросы к контракту и E2E.
2. SM-2 «Единая правда об объектах» — проверяется сценариями ниже: запросы к контракту и E2E.
3. FR-25 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-07-06-BE и ED-07-06-FE.
4. FR-29 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-07-06-BE и ED-07-06-FE.
5. FR-34 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-07-06-BE и ED-07-06-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в проекте есть сценарий с идентификатором из пути;
   2. действие — GET /api/scenarios/{sid}/intents;
   3. ожидается — ответ соответствует схеме контракта; состав и порядок элементов как в BE-доке.

# Проверки БД

Операция не меняет данные в базе: проверки БД не требуются.

# E2E (Playwright)

1. UJ-2 «Собрать сценарий диалога»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Список интентов сценария» по шагам FE-дока этой фичи;
   3. ожидается — Возвращает интенты, подключённые к сценарию, в порядке подключения.
