1. При получении запроса PUT /api/scenarios/{id}/changelog сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'scenarios' запись, где 'scenarios.id' = 'id':

      1. если запись не найдена → NotFoundError.
   3. Валидировать запрос:

      1. 'rows' — по умолчанию пустой список.
   4. Удалить записи таблицы 'scenario_changelog', где 'scenario_id' = 'id'.
   5. Создать записи в таблице 'scenario_changelog' по элементам 'rows': 'task', 'author', 'description', 'position' = индекс элемента.
   6. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД                        |
|:---------------|:-------------------------------------|
| []             | строки 'scenario_changelog' сценария |
| [].task        | 'scenario_changelog.task'            |
| [].author      | 'scenario_changelog.author'          |
| [].description | 'scenario_changelog.description'     |
