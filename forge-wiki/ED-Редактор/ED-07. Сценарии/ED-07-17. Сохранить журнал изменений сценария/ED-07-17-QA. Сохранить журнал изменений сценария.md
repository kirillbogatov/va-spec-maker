# Критерии успеха

1. SM-12 «История и журнал различаются» — проверяется сценариями ниже: запросы к контракту.
2. FR-40 из BR-Бизнес требования выполняется: поведение совпадает с документами фичи.

# Проверки

1. Успешный запрос:

   1. предусловие — существует сценарий с идентификатором из пути;
   2. действие — PUT /api/scenarios/{id}/changelog;
   3. ожидается — ответ содержит обновлённые значения; повторный GET возвращает их же.
2. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — PUT /api/scenarios/{id}/changelog;
   3. ожидается — NotFoundError.

# Проверки БД

Журнал заменён переданными строками:

```sql
SELECT position, task, author, description FROM scenario_changelog WHERE scenario_id = :id ORDER BY position;
```

# E2E (Playwright)

1. UJ-8 «Разобраться, что и когда менялось в сценарии»:

   1. предусловие — нет экранов у этой операции; сквозная проверка — в E2E связанных экранов;
   2. шаги — вызов PUT /api/scenarios/{id}/changelog происходит из интерфейса при выполнении сценария, описанного в E2E связанных фич раздела;
   3. ожидается — Полностью заменяет строки журнала изменений сценария.
