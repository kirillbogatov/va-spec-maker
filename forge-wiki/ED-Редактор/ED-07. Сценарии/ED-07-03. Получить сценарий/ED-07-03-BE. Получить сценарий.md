1. При получении запроса GET /api/scenarios/{id} сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'scenarios' запись, где 'scenarios.id' = 'id':

      1. если запись не найдена → NotFoundError.
   3. Если у сценария нет ни одной записи в 'scenario_parts' → создать вкладку с 'name' = 'scenarios.name'.
   4. Найти связанные записи:

      1. 'scenario_entities', 'scenario_dependencies' — по 'position';
      2. 'scenario_parts' — по 'position';
      3. 'scenario_steps' каждой вкладки — по 'position';
      4. 'scenario_states' каждой вкладки.
   5. Для состояний без записи в 'scenario_states' взять положение из 'scenario_parts.layout'.
   6. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API      | Параметр в БД                                                                  |
|:--------------------|:-------------------------------------------------------------------------------|
| id                  | 'scenarios.id'                                                                 |
| project_id          | 'scenarios.project_id'                                                         |
| name                | 'scenarios.name'                                                               |
| description         | 'scenarios.description'                                                        |
| entities[]          | строки таблицы 'scenario_entities'                                             |
| dependencies[]      | строки таблицы 'scenario_dependencies'                                         |
| parts[].name        | 'scenario_parts.name'                                                          |
| parts[].description | 'scenario_parts.description'                                                   |
| parts[].steps[]     | строки таблицы 'scenario_steps' вкладки                                        |
| parts[].layout      | 'scenario_parts.layout' (положение) и 'scenario_states' (содержимое состояний) |
