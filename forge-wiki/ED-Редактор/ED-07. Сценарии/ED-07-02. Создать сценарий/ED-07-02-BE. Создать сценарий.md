1. При получении запроса POST /api/projects/{pid}/scenarios сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Валидировать запрос:

      1. 'name' после удаления пробелов по краям не пусто, иначе BadRequestError.
   3. Найти в таблице 'projects' запись, где 'projects.id' = 'pid':

      1. если запись не найдена → NotFoundError.
   4. Создать запись в таблице 'scenarios': 'project_id' = 'pid', 'name'.
   5. Создать запись в таблице 'scenario_parts': 'scenario_id' созданного сценария, 'position' = 0, 'name' = 'name'.
   6. Создать запись в таблице 'scenario_history' о создании сценария.
   7. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД    |
|:---------------|:-----------------|
| id             | 'scenarios.id'   |
| name           | 'scenarios.name' |
