# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются. Действие вызывается из раздела «Сценарии».

# Метод

1. POST /api/projects/{pid}/scenarios

# Функциональные требования

1. Форма создания с полем:

   1. «Название» ('name').
2. Название нового сценария начинается с префикса проекта ([Настройки проекта](<ED-09-03-FE. Настройки проекта>)).
3. По подтверждению формы вызвать POST /api/projects/{pid}/scenarios:

   1. передать значения:

      1. 'pid' — идентификатор открытого проекта;
      2. 'name' — из поля формы;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
4. Обновить список и открыть созданный сценарий.
