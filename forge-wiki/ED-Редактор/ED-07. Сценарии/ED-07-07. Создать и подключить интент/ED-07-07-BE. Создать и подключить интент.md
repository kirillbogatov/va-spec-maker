1. При получении запроса POST /api/scenarios/{sid}/intents сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'scenarios' запись, где 'scenarios.id' = 'sid':

      1. если запись не найдена → NotFoundError.
   3. Создать интент так же, как в [Создать интент](<ED-02-02. Создать интент>), в проекте сценария.
   4. Создать запись в таблице 'scenario_intents': 'scenario_id' = 'sid', 'intent_id' созданного интента, 'position' = следующий по порядку.
   5. Записать подключение в 'scenario_history'.
   6. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД  |
|:---------------|:---------------|
| id             | 'intents.id'   |
| name           | 'intents.name' |
