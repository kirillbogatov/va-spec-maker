1. При получении запроса GET /api/scenarios/{sid}/prompts сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'scenario_prompts' все записи, где 'scenario_id' = 'sid', и соответствующие записи 'prompts'.
   3. Применить сортировку:

      1. 'scenario_prompts.position' — ASC;
      2. 'scenario_prompts.id' — ASC.
   4. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД                                                      |
|:---------------|:-------------------------------------------------------------------|
| []             | строки 'scenario_prompts' сценария                                 |
| [].id          | 'prompts.id'                                                       |
| [].name        | 'prompts.name'                                                     |
| [].has_answer  | 'prompts.full_answers' не равно '[]'                               |
| [].step_count  | число записей 'scenario_steps' и 'scenario_states' с этим промптом |
| [].hint        | первый непустой элемент 'prompts.full_answers'                     |
| [].scenarios[] | сценарии промпта через 'scenario_prompts'                          |
