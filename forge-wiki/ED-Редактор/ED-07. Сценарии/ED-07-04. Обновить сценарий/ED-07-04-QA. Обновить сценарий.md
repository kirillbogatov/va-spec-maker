# Проверки

1. Успешный запрос:

   1. предусловие — существует сценарий с идентификатором из пути; в теле переданы 'name' = 'SC_свет'; 'description' = 'Управление освещением';
   2. действие — PUT /api/scenarios/{id};
   3. ожидается — ответ содержит обновлённые значения; повторный GET возвращает их же.
2. Пустое название:

   1. предусловие — существует сценарий с идентификатором из пути;
   2. действие — PUT /api/scenarios/{id} с 'name' = пустая строка;
   3. ожидается — BadRequestError.
3. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — PUT /api/scenarios/{id};
   3. ожидается — NotFoundError.
