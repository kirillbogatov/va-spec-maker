# Критерии успеха

1. SM-1 «Полный цикл без разработчика» — проверяется сценариями ниже: запросы к контракту и E2E.
2. SM-2 «Единая правда об объектах» — проверяется сценариями ниже: запросы к контракту и E2E.
3. FR-29 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-07-12-BE и ED-07-12-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в проекте есть сценарий с идентификатором из пути; в проекте есть промпт с идентификатором из пути;
   2. действие — PUT /api/scenarios/{sid}/prompts/{pid};
   3. ожидается — ответ содержит обновлённые значения; повторный GET возвращает их же.
2. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — PUT /api/scenarios/{sid}/prompts/{pid};
   3. ожидается — NotFoundError.

# Проверки БД

Промпт подключён:

```sql
SELECT scenario_id, prompt_id FROM scenario_prompts WHERE scenario_id = :sid AND prompt_id = :pid;
```

# E2E (Playwright)

1. UJ-2 «Собрать сценарий диалога»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Подключить промпт к сценарию» по шагам FE-дока этой фичи;
   3. ожидается — Подключает существующий промпт проекта к сценарию.
