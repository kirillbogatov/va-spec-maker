1. При получении запроса POST /api/projects/{pid}/dependency-dictionary сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Валидировать запрос:

      1. 'name' после удаления пробелов по краям не пусто, иначе BadRequestError.
   3. Найти в таблице 'projects' запись, где 'projects.id' = 'pid':

      1. если запись не найдена → NotFoundError.
   4. Создать запись в таблице 'dependency_dictionary': 'project_id' = 'pid', 'name':

      1. если в проекте уже есть зависимость с таким 'name' → DuplicateError.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД                |
|:---------------|:-----------------------------|
| id             | 'dependency_dictionary.id'   |
| name           | 'dependency_dictionary.name' |
| values         | пустой список                |
