# Критерии успеха

1. SM-5 «Ключевые слова считаются верно» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-21 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-05-04-BE и ED-05-04-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — существует зависимость с идентификатором из пути; в теле переданы 'name' = 'DEP_режим'; 'values' = [дом, улица];
   2. действие — PUT /api/dependency-dictionary/{id};
   3. ожидается — ответ содержит обновлённые значения; повторный GET возвращает их же.
2. Пустое название:

   1. предусловие — существует зависимость с идентификатором из пути;
   2. действие — PUT /api/dependency-dictionary/{id} с 'name' = пустая строка;
   3. ожидается — BadRequestError.
3. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — PUT /api/dependency-dictionary/{id};
   3. ожидается — NotFoundError.
4. Повтор названия:

   1. предусловие — в проекте уже есть объект с тем же названием (проверяется без учёта регистра);
   2. действие — PUT /api/dependency-dictionary/{id} с тем же 'name';
   3. ожидается — DuplicateError.

# Проверки БД

Запись таблицы 'dependency_dictionary' обновлена:

```sql
SELECT * FROM dependency_dictionary WHERE id = :id;
```
