1. При получении запроса GET /api/projects/{pid}/dependency-dictionary сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'dependency_dictionary' все записи, где 'project_id' = 'pid'.
   3. Для каждой записи найти сценарии, где зависимость используется.
   4. Применить сортировку:

      1. 'dependency_dictionary.name' — ASC.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД                                                                                                                                          |
|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| []             | строки таблицы 'dependency_dictionary'                                                                                                                 |
| [].id          | 'dependency_dictionary.id'                                                                                                                             |
| [].name        | 'dependency_dictionary.name'                                                                                                                           |
| [].values      | 'dependency_dictionary.values'                                                                                                                         |
| [].used_by[]   | 'scenarios.id', 'scenarios.name' сценариев, где 'scenario_dependencies.name' = 'dependency_dictionary.name' и 'scenario_dependencies.entity_id' = null |
