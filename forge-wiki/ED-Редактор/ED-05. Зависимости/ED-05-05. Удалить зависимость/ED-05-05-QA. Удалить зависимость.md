# Критерии успеха

1. SM-5 «Ключевые слова считаются верно» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-3 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-05-05-BE и ED-05-05-FE.
3. FR-21 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-05-05-BE и ED-05-05-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — существует зависимость с идентификатором из пути;
   2. действие — DELETE /api/dependency-dictionary/{id};
   3. ожидается — ответ без тела; повторный GET того же объекта возвращает NotFoundError.
2. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — DELETE /api/dependency-dictionary/{id};
   3. ожидается — NotFoundError.

# Проверки БД

Запись удалена из таблицы 'dependency_dictionary':

```sql
SELECT COUNT(*) FROM dependency_dictionary WHERE id = :id; -- ожидается 0
```

# E2E (Playwright)

1. UJ-1 «Описать словарь проекта»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Удалить зависимость» по шагам FE-дока этой фичи;
   3. ожидается — Удаляет зависимость из справочника; зависимости сценариев с тем же названием остаются.
2. UJ-2 «Собрать сценарий диалога»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Удалить зависимость» по шагам FE-дока этой фичи;
   3. ожидается — Удаляет зависимость из справочника; зависимости сценариев с тем же названием остаются.
