# Критерии успеха

1. SM-13 «Поиск находит объекты проекта» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-27 из BR-Бизнес требования выполняется: поведение совпадает с документами фичи.

# Проверки

1. Проверка клиентского модуля без запросов к ядру:

   1. предусловие — приложение открыто в условиях, описанных в FE-доке;
   2. действие — выполнить функциональные требования ED-09-04-FE;
   3. ожидается — результат, описанный в FE-доке, без обращения к сети.

# Проверки БД

Фича работает на стороне клиента и не обращается к БД ядра напрямую: проверки БД не требуются.

# E2E (Playwright)

1. UJ-1 «Описать словарь проекта»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Глобальный поиск» по шагам FE-дока этой фичи;
   3. ожидается — Клиентские модули: Глобальный поиск; спека — ED-09-04-BE/FE в ED-Редактор.
