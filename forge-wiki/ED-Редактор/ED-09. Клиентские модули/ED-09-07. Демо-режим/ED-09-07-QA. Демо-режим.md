# Критерии успеха

1. SM-8 «Работа без сети» — проверяется сценариями ниже: запросы к контракту и E2E.
2. SM-9 «Регрессии ловятся» — проверяется сценариями ниже: запросы к контракту и E2E.
3. FR-14 из BR-Бизнес требования выполняется: поведение совпадает с документами фичи.
4. FR-15 из BR-Бизнес требования выполняется: поведение совпадает с документами фичи.

# Проверки

1. Проверка клиентского модуля без запросов к ядру:

   1. предусловие — приложение открыто в условиях, описанных в FE-доке;
   2. действие — выполнить функциональные требования ED-09-07-FE;
   3. ожидается — результат, описанный в FE-доке, без обращения к сети.

# Проверки БД

Фича работает на стороне клиента и не обращается к БД ядра напрямую: проверки БД не требуются.

# E2E (Playwright)

1. UJ-5 «Сохранить и перенести данные»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Демо-режим» по шагам FE-дока этой фичи;
   3. ожидается — Клиентские модули: Демо-режим; спека — ED-09-07-BE/FE в ED-Редактор.
2. UJ-7 «Попробовать продукт без регистрации»:

   1. предусловие — приложение открыто в демо-режиме;
   2. шаги — пользователь выполняет «Демо-режим» по шагам FE-дока этой фичи;
   3. ожидается — Клиентские модули: Демо-режим; спека — ED-09-07-BE/FE в ED-Редактор.
