# Описание

1. Экран входа показывается, пока пользователь не вошёл; приложение и данные проектов не загружаются до входа.

# Метод

1. Локальный модуль клиента, HTTP-запросов нет. Модуль 'auth': hasUsers, createUser, login, restoreSession, logout, changePassword

# Функциональные требования

1. При запуске восстановить сессию; при отсутствии пользователей показать экран «Создайте администратора», иначе — форму входа.
2. Экран «Создайте администратора»:

   1. «Логин»;
   2. «Пароль»;
   3. «Повтор пароля».
3. Правила ввода:

   1. логин — 3–32 символа (буквы, цифры, '.', '_', '-');
   2. пароль — не короче 8 символов;
   3. сообщения об ошибках на русском.
4. Неверная пара «логин — пароль» — одно общее сообщение без уточнения причины и короткая задержка перед следующей попыткой.
5. Экран входа и README сообщают, что вход защищает интерфейс, но не шифрует данные браузера, и что забытый пароль единственного администратора восстановить нельзя.
6. Меню профиля:

   1. логин и роль;
   2. контрол «Сменить пароль» — завершает сессии на других вкладках и устройствах;
   3. контрол «Выйти»;
   4. раздел «Настройки» ([Настройки проекта](<ED-09-03-FE. Настройки проекта>)).
