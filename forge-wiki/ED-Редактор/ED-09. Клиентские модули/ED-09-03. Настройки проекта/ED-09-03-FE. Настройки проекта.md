# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются. Раздел «Настройки» проекта; настройки хранятся в браузере отдельно для каждого проекта.

# Метод

1. Локальный модуль клиента, HTTP-запросов нет. Хранилище настроек браузера

# Функциональные требования

1. Блок «Префиксы названий»: поля для интентов, сущностей, промптов, зависимостей, сценариев и состояний.

   1. Значения по умолчанию: «INT_» для интентов, «PRM_» для промптов, «ST_» для состояний; остальные пустые.
   2. Префикс подставляется в название при создании нового объекта; существующие названия не меняются.
2. Блок «Как описывать интенты»: выбор одного режима:

   1. «Тренировочные фразы» — для обучения классификатора на основе ИИ;
   2. «Паттерны» — для строгих правил (rule-based модель);
   3. «Гибрид» — фразы вместе с паттернами;
   4. «Ключевые слова» — смысл фразы определяется только по наличию заданных слов.
3. Скрытые режимом данные не удаляются; справочник ключевых слов доступен только в режиме «Ключевые слова».
4. Переключатель «Нормализовать слова» (включён по умолчанию) приводит слова к начальной форме при сопоставлении ключевых слов и фраз.
5. Блок «Язык спецификации»: выбор «Русский» или «English»:

   1. язык влияет только на выгружаемую спецификацию, не на интерфейс.
