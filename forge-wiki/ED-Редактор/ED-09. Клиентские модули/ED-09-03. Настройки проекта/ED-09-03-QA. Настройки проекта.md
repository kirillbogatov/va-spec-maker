# Проверки

1. Проверка клиентского модуля без запросов к ядру:

   1. предусловие — приложение открыто в условиях, описанных в FE-доке;
   2. действие — выполнить функциональные требования ED-09-03-FE;
   3. ожидается — результат, описанный в FE-доке, без обращения к сети.

# Проверки БД

Фича работает на стороне клиента и не обращается к БД ядра напрямую: проверки БД не требуются.

1. UJ-6 «Настроить проект под правила команды»:

   2. шаги — пользователь выполняет «Настройки проекта» по шагам FE-дока этой фичи;
   3. ожидается — Клиентские модули: Настройки проекта; спека — ED-09-03-BE/FE в ED-Редактор.
