# Описание

1. Раздел доступен только роли admin; из меню профиля.

# Метод

1. Локальный модуль клиента, HTTP-запросов нет. Модуль 'auth': listUsers, createUser, resetPassword, setRole, deleteUser

# Функциональные требования

1. Отобразить таблицу пользователей:

   1. «Логин»;
   2. «Роль».
2. Контрол «Добавить» создаёт пользователя с ролью user или admin.
3. Контрол «Сбросить пароль» задаёт новый пароль и завершает сессии пользователя.
4. Контрол смены роли.
5. Контрол «Удалить» — после подтверждения.
6. Ограничения:

   1. нельзя удалить или понизить последнего администратора;
   2. нельзя удалить самого себя.
