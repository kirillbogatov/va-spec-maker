# Критерии успеха

1. SM-5 «Ключевые слова считаются верно» — проверяется сценариями ниже: запросы к контракту.
2. FR-16 из BR-Бизнес требования выполняется: поведение совпадает с документами фичи.

# Проверки

1. Успешный запрос:

   1. предусловие — существует интент с идентификатором из пути;
   2. действие — GET /api/intents/{id};
   3. ожидается — ответ соответствует схеме контракта; состав и порядок элементов как в BE-доке.
2. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — GET /api/intents/{id};
   3. ожидается — NotFoundError.

# Проверки БД

Операция не меняет данные в базе: проверки БД не требуются.

# E2E (Playwright)

1. UJ-1 «Описать словарь проекта»:

   1. предусловие — нет экранов у этой операции; сквозная проверка — в E2E связанных экранов;
   2. шаги — вызов GET /api/intents/{id} происходит из интерфейса при выполнении сценария, описанного в E2E связанных фич раздела;
   3. ожидается — Возвращает интент с фразами, паттернами и привязанными сущностями.
