1. При получении запроса GET /api/intents/{id} сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'intents' запись, где 'intents.id' = 'id':

      1. если запись не найдена → NotFoundError.
   3. Найти все записи таблиц 'intent_phrases', 'intent_patterns', 'intent_entities', где 'intent_id' = 'id'.
   4. Применить сортировку:

      1. 'position' — ASC;
      2. 'id' — ASC.
   5. Собрать 'values': фразы и паттерны одним списком по общему 'position'.
   6. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API       | Параметр в БД                                    |
|:---------------------|:-------------------------------------------------|
| id                   | 'intents.id'                                     |
| project_id           | 'intents.project_id'                             |
| name                 | 'intents.name'                                   |
| enabled              | 'intents.enabled'                                |
| comment              | 'intents.comment'                                |
| phrases[]            | 'intent_phrases.text'                            |
| patterns[]           | 'intent_patterns.text'                           |
| values[].text        | 'intent_phrases.text' или 'intent_patterns.text' |
| values[].kind        | таблица-источник строки                          |
| entities[].entity_id | 'intent_entities.entity_id'                      |
| entities[].required  | 'intent_entities.required'                       |
