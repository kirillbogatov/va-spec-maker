# Проверки

1. Успешный запрос:

   1. предусловие — существует интент с идентификатором из пути; в теле переданы 'name' = 'INT_включить_свет'; 'enabled' = true; 'values' = [{text: Включи свет, kind: phrase}]; 'entities' = [{entity_id: 2, required: true}];
   2. действие — PUT /api/intents/{id};
   3. ожидается — ответ содержит обновлённые значения; повторный GET возвращает их же.
2. Пустое название:

   1. предусловие — существует интент с идентификатором из пути;
   2. действие — PUT /api/intents/{id} с 'name' = пустая строка;
   3. ожидается — BadRequestError.
3. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — PUT /api/intents/{id};
   3. ожидается — NotFoundError.
4. Повтор названия:

   1. предусловие — в проекте уже есть объект с тем же названием (проверяется без учёта регистра);
   2. действие — PUT /api/intents/{id} с тем же 'name';
   3. ожидается — DuplicateError.

# E2E (Playwright)

1. UJ-1 «Описать словарь проекта»:

   1. предусловие — приложение открыто в демо-режиме, открыт демо-проект «Демо: умный дом»;
   2. шаги — пользователь выполняет «Обновить интент» по шагам FE-дока этой фичи;
   3. ожидается — Полностью заменяет название, признак включения, комментарий, фразы, паттерны и сущности интента; изменения попадают в историю сценариев, к которым подключён интент.
