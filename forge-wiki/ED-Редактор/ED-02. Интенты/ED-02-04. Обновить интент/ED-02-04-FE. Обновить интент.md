# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются. Форма открывается выбором интента в разделе «Интенты».

# Метод

1. GET /api/intents/{id}
2. PUT /api/intents/{id}

# Функциональные требования

1. При выборе интента вызвать GET /api/intents/{id}:

   1. передать значения:

      1. 'id' — выбранного интента;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
2. Отобразить форму:

   1. «Название» — 'name';
   2. «Вкл» — 'enabled';
   3. «Комментарий» — 'comment';
   4. блок «Сущности» — 'entities' (выбор сущности и признак «обязательная»);
   5. блок значений — 'values' в режиме описания интентов проекта ([Настройки проекта](<ED-09-03-FE. Настройки проекта>)): тренировочные фразы, паттерны, гибрид или концепты.
3. Блок значений:

   1. ввод новой фразы по Enter;
   2. контрол «Добавить несколько» — массовая вставка;
   3. поиск по значениям;
   4. массовое удаление выбранных значений;
   5. режим ключевых слов: рядом с каждой фразой показать найденные ключевые слова; ключевые слова без совпадений — пометка «не распознаны».
4. Блок «Сущности»: контрол создания новой сущности — [Создать сущность](<ED-03-02-FE. Создать сущность>); созданная сущность сразу привязывается к интенту.
5. При любом изменении формы автоматически вызвать PUT /api/intents/{id}:

   1. передать значения:

      1. 'id' — редактируемого интента;
      2. 'name', 'enabled', 'comment', 'values', 'entities' — из формы;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
6. Показать состояние автосохранения.
