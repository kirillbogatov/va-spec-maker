# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются. Действие вызывается из раздела «Интенты».

# Метод

1. DELETE /api/intents/{id}

# Функциональные требования

1. Если интент подключён к сценариям, показать в подтверждении их список ('scenarios' из списка интентов).
2. Запросить подтверждение удаления.
3. По подтверждению вызвать DELETE /api/intents/{id}:

   1. передать значения:

      1. 'id' — удаляемого объекта;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
4. Обновить список и закрыть форму удалённого объекта.
