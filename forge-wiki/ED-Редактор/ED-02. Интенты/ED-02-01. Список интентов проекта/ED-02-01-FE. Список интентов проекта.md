# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются.
2. Раздел «Интенты» проекта; переход из боковой навигации после открытия проекта.

# Метод

1. GET /api/projects/{pid}/intents

# Функциональные требования

1. При открытии раздела вызвать GET /api/projects/{pid}/intents:

   1. передать значения:

      1. 'pid' — идентификатор открытого проекта;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
2. Отобразить список объектов в левой колонке:

   1. «Название» — 'name';
   2. «Фраз» — 'phrase_count';
   3. признак отключённого интента — 'enabled' = false;
   4. краткое описание — 'hint'.
3. Пустой список — пустое состояние.
4. Группировать список на «Подключены к сценариям» (есть элементы в 'scenarios') и «Не используются».
5. Контрол поиска сокращает список по названию.
6. Контрол «Создать интент» — [Создать интент](<ED-02-02-FE. Создать интент>).
7. Для выбранного объекта:

   1. форма редактирования — [Обновить интент](<ED-02-04-FE. Обновить интент>);
   2. контрол «Удалить интент» — [Удалить интент](<ED-02-05-FE. Удалить интент>).
