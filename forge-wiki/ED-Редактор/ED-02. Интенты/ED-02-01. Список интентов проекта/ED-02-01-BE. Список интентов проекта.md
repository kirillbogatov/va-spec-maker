1. При получении запроса GET /api/projects/{pid}/intents сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'intents' все записи, где 'intents.project_id' = 'pid'.
   3. Для каждого интента найти сценарии, где 'scenario_intents.intent_id' = 'intents.id'.
   4. Применить сортировку:

      1. 'intents.name' — ASC.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API  | Параметр в БД                                                        |
|:----------------|:---------------------------------------------------------------------|
| []              | строки таблицы 'intents' проекта                                     |
| [].id           | 'intents.id'                                                         |
| [].name         | 'intents.name'                                                       |
| [].enabled      | 'intents.enabled'                                                    |
| [].phrase_count | число записей 'intent_phrases' интента                               |
| [].hint         | 'intents.comment', иначе 'intent_phrases.text' первой непустой фразы |
| [].scenarios[]  | 'scenarios.id', 'scenarios.name' через 'scenario_intents'            |
