1. При получении запроса POST /api/projects/{pid}/prompts сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'projects' запись, где 'projects.id' = 'pid':

      1. если запись не найдена → NotFoundError.
   3. Валидировать запрос:

      1. 'name' после удаления пробелов по краям не пусто, иначе BadRequestError;
      2. если в проекте есть промпт с таким же названием без учёта регистра и пробелов по краям → DuplicateError.
   4. Создать запись в таблице 'prompts': 'project_id' = 'pid', 'name'.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД  |
|:---------------|:---------------|
| id             | 'prompts.id'   |
| name           | 'prompts.name' |
