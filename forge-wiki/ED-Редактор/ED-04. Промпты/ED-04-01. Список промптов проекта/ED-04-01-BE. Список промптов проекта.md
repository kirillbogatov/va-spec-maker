1. При получении запроса GET /api/projects/{pid}/prompts сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'prompts' все записи, где 'prompts.project_id' = 'pid'.
   3. Для каждого промпта найти сценарии через 'scenario_prompts' и посчитать использования в 'scenario_steps' и 'scenario_states'.
   4. Применить сортировку:

      1. 'prompts.id' — ASC.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД                                                                   |
|:---------------|:--------------------------------------------------------------------------------|
| []             | строки таблицы 'prompts'                                                        |
| [].id          | 'prompts.id'                                                                    |
| [].name        | 'prompts.name'                                                                  |
| [].has_answer  | 'prompts.full_answers' не равно '[]'                                            |
| [].step_count  | число записей 'scenario_steps' и 'scenario_states' с 'prompt_id' = 'prompts.id' |
| [].hint        | первый непустой элемент 'prompts.full_answers'                                  |
| [].scenarios[] | 'scenarios.id', 'scenarios.name' через 'scenario_prompts'                       |
