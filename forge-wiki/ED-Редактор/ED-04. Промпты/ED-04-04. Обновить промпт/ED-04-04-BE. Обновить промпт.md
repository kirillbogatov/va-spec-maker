1. При получении запроса PUT /api/prompts/{id} сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'prompts' запись, где 'prompts.id' = 'id':

      1. если запись не найдена → NotFoundError.
   3. Валидировать запрос:

      1. 'name' после удаления пробелов по краям не пусто, иначе BadRequestError;
      2. если в проекте есть другой промпт с таким же названием без учёта регистра и пробелов по краям → DuplicateError;
      3. в 'full_answers' удалить пробелы по краям и отбросить пустые элементы.
   4. Обновить запись в таблице 'prompts': 'name', 'full_answers' (JSON-массив).
   5. Записать изменение промпта в 'scenario_history' сценариев, к которым он подключён.
   6. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД          |
|:---------------|:-----------------------|
| id             | 'prompts.id'           |
| project_id     | 'prompts.project_id'   |
| name           | 'prompts.name'         |
| full_answers   | 'prompts.full_answers' |
