2. FR-17 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-03-02-BE и ED-03-02-FE.
3. FR-18 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-03-02-BE и ED-03-02-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — в приложении есть проект с идентификатором из пути; в теле переданы 'name' = 'ENT_комната'; 'type' = 'string';
   2. действие — POST /api/projects/{pid}/entities;
   3. ожидается — объект создан, в ответе его идентификатор и переданные значения.
2. Пустое название:

   1. предусловие — в приложении есть проект с идентификатором из пути;
   2. действие — POST /api/projects/{pid}/entities с 'name' = пустая строка;
   3. ожидается — BadRequestError.
3. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — POST /api/projects/{pid}/entities;
   3. ожидается — NotFoundError.
4. Повтор названия:

   1. предусловие — в проекте уже есть объект с тем же названием (проверяется без учёта регистра);
   2. действие — POST /api/projects/{pid}/entities с тем же 'name';
   3. ожидается — DuplicateError.

# Проверки БД

Запись создана в таблице 'entities':

```sql
SELECT id, name FROM entities WHERE id = :id AND name = :name;
```
