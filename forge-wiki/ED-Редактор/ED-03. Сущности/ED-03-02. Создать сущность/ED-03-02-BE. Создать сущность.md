1. При получении запроса POST /api/projects/{pid}/entities сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Валидировать запрос:

      1. 'name' после удаления пробелов по краям не пусто, иначе BadRequestError;
      2. 'type' — по умолчанию 'string'; значение вне перечня 'string', 'number', 'time', 'date', 'boolean' → BadRequestError;
      3. для 'string' и 'boolean' передача 'range_min' или 'range_max' → BadRequestError;
      4. формат границы: number — десятичное число, time — 'ЧЧ:ММ', date — 'ГГГГ-ММ-ДД' существующей даты, иначе BadRequestError;
      5. если обе границы заданы и 'range_min' больше 'range_max' → BadRequestError.
   3. Найти в таблице 'projects' запись, где 'projects.id' = 'pid':

      1. если запись не найдена → NotFoundError.
   4. Создать запись в таблице 'entities': 'project_id' = 'pid', 'name', 'type', 'range_min', 'range_max':

      1. если в проекте уже есть сущность с таким 'name' → DuplicateError.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API | Параметр в БД        |
|:---------------|:---------------------|
| id             | 'entities.id'        |
| name           | 'entities.name'      |
| type           | 'entities.type'      |
| range_min      | 'entities.range_min' |
| range_max      | 'entities.range_max' |
