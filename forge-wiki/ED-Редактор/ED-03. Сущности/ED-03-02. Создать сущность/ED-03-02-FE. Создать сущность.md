# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются. Действие вызывается из раздела «Сущности».

# Метод

1. POST /api/projects/{pid}/entities

# Функциональные требования

1. Форма создания с полем:

   1. «Название» ('name').
2. Название нового объекта начинается с префикса проекта (см. [Настройки проекта](<ED-09-03-FE. Настройки проекта>)).
3. По подтверждению формы вызвать POST /api/projects/{pid}/entities:

   1. передать значения:

      1. 'pid' — идентификатор открытого проекта;
      2. 'name' — из поля формы;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
4. Для типа number, time, date показать поля «от» и «до» ('range_min', 'range_max'); обновить список и открыть созданную сущность.
