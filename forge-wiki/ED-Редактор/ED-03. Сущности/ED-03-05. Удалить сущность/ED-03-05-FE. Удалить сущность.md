# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются. Действие вызывается из раздела «Сущности».

# Метод

1. DELETE /api/entities/{id}

# Функциональные требования

1. Вызвать DELETE /api/entities/{id}:

   1. передать значения:

      1. 'id' — удаляемой сущности;
      2. 'force' — без значения при первом вызове;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
2. Если сервис вернул InUseError, показать перечень интентов из 'details.intents' и запросить подтверждение.
3. По подтверждению повторить вызов DELETE /api/entities/{id}:

   1. передать значения:

      1. 'id' — удаляемой сущности;
      2. 'force' — 1;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
4. Обновить список и закрыть форму удалённой сущности.
