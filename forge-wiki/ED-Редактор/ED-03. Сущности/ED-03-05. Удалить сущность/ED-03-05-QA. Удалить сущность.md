# Критерии успеха

1. SM-10 «Типы сущностей работают» — проверяется сценариями ниже: запросы к контракту и E2E.
2. FR-3 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-03-05-BE и ED-03-05-FE.
3. FR-18 из BR-Бизнес требования выполняется: наблюдаемое поведение совпадает с ED-03-05-BE и ED-03-05-FE.

# Проверки

1. Успешный запрос:

   1. предусловие — существует сущность с идентификатором из пути;
   2. действие — DELETE /api/entities/{id} с 'force' = '1';
   3. ожидается — ответ без тела; повторный GET того же объекта возвращает NotFoundError.
2. Объект не найден:

   1. предусловие — идентификатор в пути не принадлежит ни одному объекту (например, 999999);
   2. действие — DELETE /api/entities/{id};
   3. ожидается — NotFoundError.
3. Сущность используется:

   1. предусловие — сущность привязана к интенту;
   2. действие — DELETE /api/entities/{id} без 'force';
   3. ожидается — InUseError; в 'details.intents' перечень интентов.
4. Принудительное удаление:

   1. предусловие — сущность привязана к интенту;
   2. действие — DELETE /api/entities/{id} с 'force' = '1';
   3. ожидается — сущность удалена, привязка к интенту удалена.

# Проверки БД

Запись удалена из таблицы 'entities':

```sql
SELECT COUNT(*) FROM entities WHERE id = :id; -- ожидается 0
```
