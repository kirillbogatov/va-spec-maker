1. При получении запроса GET /api/projects/{pid}/entities сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'entities' все записи, где 'entities.project_id' = 'pid'.
   3. Для каждой сущности найти записи 'entity_values' и интенты через 'intent_entities' (с их сценариями через 'scenario_intents').
   4. Применить сортировку:

      1. 'entities.name' — ASC;
      2. 'entity_values.position' — ASC.
   5. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API            | Параметр в БД                                        |
|:--------------------------|:-----------------------------------------------------|
| []                        | строки таблицы 'entities' проекта                    |
| [].id                     | 'entities.id'                                        |
| [].project_id             | 'entities.project_id'                                |
| [].name                   | 'entities.name'                                      |
| [].description            | 'entities.description'                               |
| [].multiple_values        | 'entities.multiple_values'                           |
| [].type                   | 'entities.type'                                      |
| [].range_min              | 'entities.range_min'                                 |
| [].range_max              | 'entities.range_max'                                 |
| [].values[].value         | 'entity_values.value'                                |
| [].values[].synonyms      | 'entity_values.synonyms'                             |
| [].used_by[]              | 'intents.id', 'intents.name' через 'intent_entities' |
| [].used_by[].scenario_ids | 'scenario_intents.scenario_id'                       |
| [].value_count            | число записей 'entity_values' сущности               |
