# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются.
2. Раздел «Сущности» проекта; переход из боковой навигации после открытия проекта.

# Метод

1. GET /api/projects/{pid}/entities

# Функциональные требования

1. При открытии раздела вызвать GET /api/projects/{pid}/entities:

   1. передать значения:

      1. 'pid' — идентификатор открытого проекта;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
2. Отобразить список объектов в левой колонке:

   1. «Название» — 'name';
   2. метка типа — 'type' ([Строка, Число, Время, Дата, Логический]);
   3. предупреждение «нет значений» — только у строковой сущности без значений ('value_count' = 0).
3. Пустой список — пустое состояние.
4. Контрол «Создать сущность» — [Создать сущность](<ED-03-02-FE. Создать сущность>).
5. Для выбранного объекта:

   1. форма редактирования — [Обновить сущность](<ED-03-04-FE. Обновить сущность>);
   2. контрол «Удалить сущность» — [Удалить сущность](<ED-03-05-FE. Удалить сущность>).
