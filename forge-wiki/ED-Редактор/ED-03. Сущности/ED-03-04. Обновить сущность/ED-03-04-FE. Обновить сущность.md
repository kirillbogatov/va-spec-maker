# Описание

1. Доступно любому вошедшему пользователю; права на отдельные проекты и разделы не различаются. Форма открывается выбором сущности в разделе «Сущности».

# Метод

1. GET /api/entities/{id}
2. PUT /api/entities/{id}

# Функциональные требования

1. При выборе сущности вызвать GET /api/entities/{id}:

   1. передать значения:

      1. 'id' — выбранной сущности;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
2. Отобразить форму:

   1. «Название» — 'name';
   2. «Тип» — 'type';
   3. переключатель «несколько значений» — 'multiple_values';
   4. для типа string — таблица значений: «Значение» — 'values[].value', «Синонимы» — 'values[].synonyms';
   5. для типов number, time, date — поля «от» и «до» ('range_min', 'range_max'; тип поля ввода соответствует типу сущности);
   6. для типа boolean — подсказка «true/false»;
   7. список «Используется в» — 'used_by' со ссылками на сценарии ('used_by[].scenario_ids').
3. Контрол массовой вставки значений принимает строки вида «значение: синоним1, синоним2».
4. При смене типа сущности с непустыми значениями или диапазоном запросить подтверждение очистки.
5. При любом изменении формы автоматически вызвать PUT /api/entities/{id}:

   1. передать значения:

      1. 'id' — редактируемой сущности;
      2. 'name', 'description', 'multiple_values', 'type', 'range_min', 'range_max', 'values' — из формы;
   2. ошибка — [обработать общие ошибки](<GEN-01. Обработка запросов и ошибок>).
