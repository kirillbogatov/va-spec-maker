1. При получении запроса PUT /api/entities/{id} сервер должен:

   1. [Проверить на общие ошибки](<GEN-01. Обработка запросов и ошибок>).
   2. Найти в таблице 'entities' запись, где 'entities.id' = 'id':

      1. если запись не найдена → NotFoundError.
   3. Валидировать запрос:

      1. 'name' после удаления пробелов по краям не пусто, иначе BadRequestError;
      2. если в проекте есть другая сущность с таким 'name' → DuplicateError;
      3. тип и диапазон — по тем же правилам, что в [Создать сущность](<ED-03-02. Создать сущность>); если 'type' не передан → оставить текущий тип;
      4. если 'type' не равен 'string' → 'values' игнорировать;
      5. значения с пустым 'value' отбросить, пустые синонимы отбросить.
   4. Обновить запись в таблице 'entities': 'name', 'description', 'multiple_values', 'type', 'range_min', 'range_max'.
   5. Удалить записи 'entity_values' сущности.
   6. Создать записи в 'entity_values' по элементам 'values': 'value', 'synonyms' (JSON-массив), 'position' = индекс элемента.
   7. Вернуть ответ клиенту.

## Маппинг ответа

| Параметр в API         | Параметр в БД                                        |
|:-----------------------|:-----------------------------------------------------|
| id                     | 'entities.id'                                        |
| project_id             | 'entities.project_id'                                |
| name                   | 'entities.name'                                      |
| description            | 'entities.description'                               |
| multiple_values        | 'entities.multiple_values'                           |
| type                   | 'entities.type'                                      |
| range_min              | 'entities.range_min'                                 |
| range_max              | 'entities.range_max'                                 |
| values[].value         | 'entity_values.value'                                |
| values[].synonyms      | 'entity_values.synonyms'                             |
| used_by[]              | 'intents.id', 'intents.name' через 'intent_entities' |
| used_by[].scenario_ids | 'scenario_intents.scenario_id'                       |
