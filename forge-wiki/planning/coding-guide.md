# Coding Guide

## Стек и версии
- TypeScript ~6.0, npm workspaces: 'core' (ядро), 'web' (интерфейс).
- Ядро: sql.js ^1.13 (SQLite в WASM), docx ^9.12 (Word), vitest ^5.
- Интерфейс: React ^19, Vite ^8, Tailwind ^4, shadcn/base-ui, TanStack Query ^5, react-router-dom ^7 (HashRouter), @xyflow/react и elkjs (схема состояний), dnd-kit (перетаскивание), sonner (уведомления).
- Тесты: vitest в 'core/test' и 'web/src/**/*.test.ts'. Команды: 'npm test', 'npm run build', 'npm run build:demo'.

## Критические правила реализации
- Запросы клиента идут в локальный роутер 'core/src/app.ts' (createApp().handle); HTTP нет. Новый маршрут — файл в 'core/src/routes' и подключение в 'createApp'.
- Любая запись в БД ядра идёт через 'Db' из 'core/src/sqlite.ts'; сохранение базы в IndexedDB — 'web/src/lib/backend.ts'.
- Схема БД меняется только добавлением: новая колонка — в SCHEMA и в 'migrate' с увеличением 'user_version'; существующие колонки не удаляются.
- Сопоставление ключевых слов и стеммер — только в 'core' (AD-06); интерфейс импортирует их из '@va/core'.
- Сохранение сценария — полная замена содержимого (AD-07); не опираться на идентификаторы вкладок, состояний и строк.
- Настройки проекта — localStorage (AD-05); в дамп проекта не входят.

## Язык и формат
- Основной язык документации и сообщений интерфейса: русский. Технические термины, имена полей, эндпоинты: английский.
- Именование: колонки БД — 'snake_case'; поля API — как в 'openapi/app'.
- Значения enum в БД — строчные (as-is, см. discrepancies).

## Принципы разработки (обязательны)
- Каждое утверждение в спеке имеет источник: код, схема БД, дизайн-спека.
- Неизвестное поведение — открытый вопрос, не догадка.
- As-is и to-be раздельно: расхождения — в 'discrepancies.md'.
