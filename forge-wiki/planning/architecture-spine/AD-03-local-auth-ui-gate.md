# AD-03 — Авторизация — локальная и закрывает только интерфейс [ADOPTED]

- **Decision:** Авторизация — локальная и закрывает только интерфейс; запросы ядра не авторизуются, прав и ролей на уровне запросов нет.
- **Binds:** CAP-12.
- **Prevents:** ложное ощущение защиты данных.
- **Rule:** Реестра openapi/app/permissions нет; в BE-доках шага «Авторизовать запрос» нет; пользователи и сессии хранятся отдельной базой IndexedDB с PBKDF2-SHA256 (310 000 итераций); роль admin нужна только для управления пользователями.
