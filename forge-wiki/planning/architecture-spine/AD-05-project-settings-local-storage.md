# AD-05 — Настройки проекта (префиксы, режим интентов, нормализация, язык спецификации) хранятся в localStorage браузера для каждого проекта и передаются в запросы экспорта параметрами [ADOPTED]

- **Decision:** Настройки проекта (префиксы, режим интентов, нормализация, язык спецификации) хранятся в localStorage браузера для каждого проекта и передаются в запросы экспорта параметрами.
- **Binds:** ED-09-03, ED-08.
- **Prevents:** настройки на сервере или в JSON-копии проекта.
- **Rule:** Настройки не входят в дамп проекта; ядро получает режим и язык только параметрами запросов предпросмотра и выгрузки.
