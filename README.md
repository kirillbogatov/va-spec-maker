# VA Spec Maker

Редактор спецификаций голосовых ассистентов. Описывайте интенты, сущности, промпты и сценарии (с диаграммой состояний) и экспортируйте готовую спецификацию в **Word (.docx)** и **Markdown** на русском языке.

**Live-демо:** _ссылка появится после публикации на GitHub Pages_ (`https://<пользователь>.github.io/<репозиторий>/`)

## Возможности

- Несколько проектов: создание, переименование, дублирование, удаление, импорт и экспорт в JSON.
- Интенты с тренировочными фразами и сущностями, справочники сущностей и зависимостей.
- Сценарии с несколькими вкладками, редактором диаграммы состояний и проверкой готовности к экспорту.
- Экспорт сценария или всего проекта: «Интенты», «Сущности», «Промпты», «Переходы между состояниями», «Ошибки».
- Поиск по всем объектам проекта (Ctrl+K).

## Данные и приватность

Сервера нет: приложение целиком работает в браузере, данные хранятся в IndexedDB вашего браузера и никуда не отправляются. Для резервной копии или переноса на другое устройство используйте экспорт проекта в JSON (меню «⋯» на карточке проекта) и импорт.

## Запуск локально

На Windows достаточно запустить `start.bat`: он установит зависимости, поднимет сервер разработки и откроет браузер. Вручную:

    npm install
    npm run dev       # http://localhost:5173
    npm test          # тесты ядра и клиента
    npm run build     # статическая сборка в web/dist

## Устройство

- `core/` — ядро без привязки к окружению: SQLite (sql.js, WASM), маршруты, экспорт. Работает и в браузере, и в тестах под Node.
- `web/` — интерфейс на React, Vite и Tailwind.

## Публикация

При пуше в `main` GitHub Actions собирает проект и публикует его на GitHub Pages (в настройках репозитория: Settings → Pages → Source: GitHub Actions).
