# VA Spec Maker

Редактор спецификаций голосовых ассистентов на русском и английском языках. Создавайте проекты, описывайте интенты, сущности, промпты и сценарии с диаграммами состояний, а затем экспортируйте спецификацию в Word (.docx) или Markdown. Импорт и экспорт проекта в JSON помогают создавать резервную копию и переносить данные.

**Демо:** запустите `npm run dev:demo` и откройте адрес из терминала. Демо работает без входа и открывает готовый проект «Умный дом». Данные демо сохраняются в `sessionStorage` текущей вкладки и удаляются после её закрытия.

## Возможности

- Проекты с ветками: создание, клонирование, переключение и удаление веток.
- Интенты с тренировочными фразами и сущностями, справочники сущностей и зависимостей.
- Промпты с вариантами полного и короткого ответа.
- Шаблоны ответов и сценариев. Шаблон ответа можно использовать для создания независимого промпта. Сценарии и шаблоны редактируются в общем редакторе; сценарий можно создать из шаблона или сохранить как шаблон.
- При создании обычного сценария из шаблона его интенты и промпты копируются как независимые элементы проекта; сущности и зависимости остаются общими справочниками.
- Сценарии с несколькими вкладками, диаграммой состояний, историей изменений и проверкой готовности к экспорту.
- История изменений справочников: создание, удаление и сохранённые изменения, в том числе при импорте. Повторное сохранение без изменений запись не создаёт. История включается в JSON-копию проекта.
- Экспорт сценария или всего проекта: интенты, сущности, промпты, переходы между состояниями и ошибки.
- Поиск по объектам проекта клавишей `/`; светлая, тёмная и системная темы.
- Вход по логину и паролю. Первый пользователь становится администратором и может управлять пользователями; настройки пользователя позволяют изменить имя, email и пароль.

## Данные и приватность

Серверного хранения нет: приложение работает в браузере, данные проектов хранятся в IndexedDB. Учетные записи, email и хеши паролей хранятся в браузере отдельно от проектов. Вход защищает интерфейс, но не шифрует данные браузера. Администратор может сбросить пароль пользователя. Если потерян пароль единственного администратора, восстановить его нельзя: очистите данные сайта и импортируйте проекты из JSON-копии.

Для резервной копии или переноса проекта используйте экспорт в JSON (меню `⋯` на карточке проекта), а затем импортируйте файл на другом устройстве.

## Локальный запуск

В Windows можно запустить `start.bat`: он установит зависимости, запустит сервер разработки и откроет браузер. Вручную из корня проекта:

```sh
npm install
npm run dev          # http://localhost:5173
npm test             # тесты ядра и клиента
npm run build        # статическая сборка в web/dist
npm run dev:demo     # демо без входа
npm run build:demo   # сборка демо в web/dist
```

Для запуска Playwright-сценариев используйте `npm run e2e`.

## Устройство

- `core/` — ядро без привязки к интерфейсу: SQLite на sql.js/WASM, маршруты и экспорт; используется приложением и тестами Node.
- `web/` — интерфейс на React, Vite и Tailwind.

## Публикация демо

Демо публикуется на GitHub Pages автоматически при push в ветку `main`; workflow запускает `npm ci`, `npm test` и `npm run build:demo`, затем размещает `web/dist`. Для локальной сборки выполните `npm run build:demo`. Если размещаете приложение в подкаталоге, задайте `BASE_PATH` перед сборкой.
